# 手机号码查询API服务

这是一个基于Python和Flask的手机号码查询API服务，可以通过号段匹配手机号码的前7位，获取手机号码归属的省区、城市、服务商、区号、邮编和区划代码等信息。

## 功能特点

- 支持查询1开头的11位手机号码
- 通过匹配前7位号段获取号码归属地信息
- 提供JSON格式的查询结果
- 包含简洁的Web界面，方便直接在浏览器中使用

## 安装与运行

### 前提条件

- Python 3.6+
- PhoneNumber.csv 文件（包含手机号码数据）

### 安装依赖

```bash
pip install -r requirements.txt
```

### 启动服务

```bash
python app.py
```

启动后，服务将在 http://localhost:5001 上运行。

## API使用说明

### 查询手机号码信息

**请求方式**：GET

**URL**：`/query?phone={phone_number}`

**参数**：
- `phone_number`：11位手机号码（1开头）

**成功响应示例**：
```json
{
  "success": true,
  "phone": "13000001234",
  "data": {
    "省区": "江苏",
    "城市": "常州",
    "服务商": "中国联通",
    "区号": "0519",
    "邮编": "213000",
    "区划代码": "320400"
  }
}
```

**失败响应示例**：
```json
{
  "success": false,
  "message": "未找到号码 13000001234 的信息"
}
```

## Web界面

访问 http://localhost:5001 可以使用内置的Web界面进行手机号码查询。

## 数据来源

服务使用项目根目录下的`PhoneNumber.csv`文件作为数据源，该文件包含手机号段与归属地信息的映射关系。
